# ANAMIX Research Website

A modern, responsive website for ANAMIX RESEARCH PVT. LTD., a leading market research company with PAN India coverage and 50+ years of combined experience.

## 🚀 Features

- **Modern Design**: Clean, professional interface with vibrant blue/cyan color scheme
- **Responsive Layout**: Optimized for all devices and screen sizes
- **Interactive Elements**: Smooth animations and hover effects throughout
- **Timeline-based Expansion Story**: Unique visualization of company growth
- **Regional Coverage Display**: Comprehensive showcase of nationwide presence
- **Performance Optimized**: Fast loading with Next.js 15 and modern web practices

## 🛠️ Tech Stack

- Next.js 15 (App Router)
- Tailwind CSS
- shadcn/ui
- TypeScript
- Lucide React Icons

## 🚀 Quick Setup

### Prerequisites
- Node.js 18+
- npm or yarn

### Installation

1. **Clone and install**
   ```bash
   git clone <repository-url>
   cd anamix-website
   npm install
   ```

2. **Run development server**
   ```bash
   npm run dev
   ```

3. **Open browser**
   Navigate to [http://localhost:3000](http://localhost:3000)

### Build for Production

```bash
npm run build
npm start
```
